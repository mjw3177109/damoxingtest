# 训练语料与评估集说明

- `safety_humanity_seed.jsonl`：原始 35 条种子语料，保留作为历史基线。
- `safety_humanity_train_v2.jsonl`：当前训练集，包含原始种子语料与新增原创合成示例，共 85 条。
- `safety_humanity_eval_v1.jsonl`：固定留出评估集，共 24 条，不参与梯度更新。

## 来源与许可
新增样例由本项目原创编写，属于合成示例；未复制用户私人聊天、密码、访问令牌或未经授权的私人数据。仍需人工审查事实性、偏见和覆盖范围。

## 质量规则
1. 每行包含非空 `instruction` 与 `response`。
2. 训练指令不得重复；训练集与固定评估集的规范化指令不得重叠。
3. 扩充数据不代表模型质量必然提升；以固定评估指标、固定生成提示和人工审核结果判断。
4. 发现错误、偏见、隐私或安全问题时，应修订或移除记录，并记录新的数据哈希。

## 版本记录
- V1：原始种子数据。
- V2：新增原创合成案例；训练集与固定评估集拆分。
